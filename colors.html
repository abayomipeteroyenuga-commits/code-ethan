MODULE 01

Color systems, from first principles

Color is data. Experiment with the picker and learn why different notations can describe the same shade.

Color Explorer

Read a HEX color

#RRGGBB has three pairs of hexadecimal digits. Each pair represents red, green or blue from 00 to FF (0–255).

#FF0000 = red; #00FF00 = green; #0000FF = blue. #000000 = black; #FFFFFF = white.

#F00 is shorthand for #FF0000. Eight-digit HEX such as #2563EB80 adds an alpha (transparency) channel.

RGB mixes red, green and blue channels. HSL describes hue, saturation and lightness. CSS also accepts named colors such as tomato.

Design with intention

Choose a background, text and accent color. Use contrast to keep words readable. Never communicate success or errors through color alone: include text or an icon.

Readable text matters.

Try to reach at least 4.5:1 contrast for ordinary text. Check different font sizes and screen conditions.

MODULE 02

Characters & symbols: the coding alphabet

Learn what the characters mean in context. The same character can behave differently in HTML, CSS and JavaScript.

< >

HTML tag delimiters

Tags mark elements; closing tags include a slash.

<h1>Title</h1>
#

CSS ID selector / HEX prefix

Before an ID it selects an element; before color digits it starts HEX.

#title { color: #2563eb; }
.

CSS class selector / JavaScript property

A dot selects a class in CSS; JavaScript uses dots to access properties.

.card { padding: 1rem; }
{ }

Code blocks and CSS declarations

Curly braces group CSS declarations and JavaScript blocks.

body { color: blue; }
( )

Function calls and conditions

Parentheses hold function arguments or condition expressions.

alert("Hello");
[ ]

Arrays and indexing

Square brackets build arrays and access indexed values.

const scores = [10, 20];
" ' `

Strings and template literals

Quotes delimit strings; backticks support JavaScript interpolation.

const name = "Ada";
;

Statement separator

Semicolons separate statements and CSS declarations.

let count = 1;
= == ===

Assignment and comparison

= assigns; == compares with coercion; === compares without coercion.

count === 1
! && ||

NOT, AND, OR

Logical operators combine or invert conditions.

ready && hasCode
&

HTML entity prefix

Entities represent special characters in HTML.

&amp;amp;
/ * + -

Operators and delimiters

Meaning depends on the language and context.

total = price * quantity;

Character Decoder

Escaping and Unicode

To show a literal < in HTML source, write &lt;. For &, write &amp;. In JavaScript, \n represents a newline in a string. Unicode gives characters unique code points, including many writing systems and emoji.

For accessible interfaces, give symbol-only buttons a readable label; never rely on an emoji as the only instruction.
